# 课堂数据通过加密资料包提供

公开Git仓库不包含明文微博数据、个人采集输出或逐条记录。
爬虫教程另保留雷军公开微博前3页的30条展示样本。
本课程学生和教师可从[课程首页](https://wybert.github.io/social-media-analysis-tutorials/)点击“下载所有资料（含数据，需密码）”，解压密码由教师在课堂提供，不在网页和仓库中公布。
含数据资料包分享至2026年10月25日23:59:59（北京时间）；已下载的副本不会自动失效。
下载和使用前请阅读[课堂数据使用与有限分享声明](../DATA_USE_TERMS.md)。
解压整个包后，`posts_two_weeks.parquet`与`posts_preview.csv`已放在本目录，无需移动。
只下载公开教程的同学，需要另行取得这两份数据并放到此目录；不要将解压后的数据提交GitHub。
Notebook从tutorials目录启动时使用相对路径 `data/posts_two_weeks.parquet`；
从仓库根目录启动时使用 `tutorials/data/posts_two_weeks.parquet`。

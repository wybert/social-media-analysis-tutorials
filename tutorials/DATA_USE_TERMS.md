## 4. 已实施的数据处理与保留信息

本次教学文件根据现有处理程序实施了以下措施。完整字段说明见同目录的 `README.md`，来源与文件校验信息见 `two_week_provenance.json`。

| 信息类型 | 已实施的处理 | 仍保留的信息及限制 |
|---|---|---|
| 用户和帖子 ID | 使用带私有密钥的 BLAKE2b 替换原数字 ID；摘要长度为10字节，显示为20位十六进制代号，分别添加 `u_` 和 `p_` 前缀。原 ID、密钥及映射表不随数据提供 | 同一原 ID 保持同一代号，因此仍可关联同一用户或帖子的记录。这属于假名化／去标识化措施，不作法律意义上完全匿名化的保证 |
| 文本 | 在源 `text_clean` 上，将 HTTP(S) 链接替换为 `[链接]`、@账号替换为 `[提及]`、连续7位及以上数字替换为 `[长数字]`；合并连续空白并去除首尾空白 | 不额外截断全文。姓名、短数字、地址、独特表述和其他身份线索可能仍存在；源文本更早的全部清洗步骤尚未核实 |
| 位置 | 对纬度18–54、经度73–135粗范围内的有效坐标，分别按 `numpy.round(坐标 / 0.02) * 0.02` 舍入；范围外或无效坐标留空，不提供原精确坐标 | 保留0.02度粗网格位置。该范围不是精确国界判定，网格不是固定米数；源坐标体系已由数据提供者确认为GCJ-02；源定位机制尚未核实 |
| 时间与行政编码 | 发帖时间统一到 `Asia/Shanghai` 时区，并派生日期；保留源日期和城市、省编码 | 发帖时间和行政标签未作进一步扰动，与文本或其他字段结合仍可能增加识别风险 |
| 质量与模型字段 | 增加重复帖子、可用文本、坐标和分数有效性标记；保留源情感标签及分数 | 质量标记不等于全部错误已消除。情感模型来源和性能未独立核实，分数不能作为个人心理健康或幸福感诊断 |

数据保留两周本地源中的1,254,689行，并提供质量标记；默认分析范围为四川可用记录。`posts_preview.csv` 是同一数据中的8行读写示例，**包含真实记录，同样受本声明约束**。本次导出不再抽样，不代表全平台覆盖或完整用户历史。

以上处理降低了部分识别风险，**不保证数据完全匿名、无法重新识别或不存在第三方权利问题**。接收者应按仍可能包含个人信息的数据谨慎使用，不得尝试验证或利用残余身份线索。
